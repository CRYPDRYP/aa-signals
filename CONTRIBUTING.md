# Contributing to AA Signals

## Code of Conduct

Be respectful, inclusive, and constructive.

## How to Contribute

1. **Report Issues** — Found a bug? Open an issue on GitHub
2. **Suggest Features** — Ideas for new signals or payment models?
3. **Submit Code** — PRs welcome for examples, docs, SDKs
4. **Test the API** — Help us improve signal quality

## Development Setup

### TypeScript Example
```bash
cd examples/typescript
npm install
npm run dev
```

### Python Example
```bash
cd examples/python
pip install -r requirements.txt
python buyer.py
```

## Commit Message Style

- `feat: add new feature`
- `fix: resolve bug`
- `docs: update documentation`
- `test: add tests`
